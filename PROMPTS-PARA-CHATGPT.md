# Prompts para usar los repositorios con ChatGPT

Reemplaza los textos entre corchetes. Conecta GitHub antes de pedir lectura o cambios sobre repositorios privados.

## Analizar un repositorio

> Analiza [URL]. Explícame en español qué hace, qué problema resuelve, requisitos, costos externos, licencia, riesgos, dificultad y si está activo. No instales ni cambies nada todavía.

## Elegir una herramienta

> Compara [URL 1], [URL 2] y [URL 3] para [OBJETIVO]. Mi sistema es Windows 11 y mi nivel técnico es [BÁSICO/MEDIO/ALTO]. Recomienda una sola opción y justifica instalación, mantenimiento, costos y riesgos.

## Instalar con seguridad

> Revisa la documentación oficial de [URL]. Crea un plan de instalación para Windows 11 usando la versión estable más reciente. Prefiere Docker si simplifica el proceso. No expongas secretos ni abras servicios a internet sin autenticación. Espera mi autorización antes de ejecutar cambios.

## Crear una aplicación

> Usa [URL] como referencia para crear una aplicación de [DESCRIPCIÓN]. Primero propón arquitectura, pantallas, datos, autenticación, costos y fases. El código debe quedar en mi repositorio [OWNER/NOMBRE], en una rama nueva. No publiques hasta que yo lo autorice.

## Adaptar una plantilla

> Inspecciona [URL]. Identifica las partes reutilizables para [OBJETIVO]. No copies marcas, secretos ni contenido protegido. Propón los archivos que cambiarías y espera mi aprobación antes de escribir.

## Automatización

> Diseña un flujo en [N8N/ACTIVEPIECES] que reciba [ENTRADA], realice [PROCESO] y entregue [SALIDA]. Incluye nodos, credenciales, manejo de errores, registro, costos y una prueba. No solicites contraseñas en texto abierto.

## Agente con Dify

> Diseña en Dify un [CHATBOT/AGENTE/FLUJO] para [OBJETIVO]. Define instrucciones, entradas, herramientas, base de conocimiento, modelo, seguridad, evaluación y costo. Entrégame primero el diseño y después guíame para configurarlo.

## Panel interno

> Diseña una app interna en [APPSMITH/TOOLJET/BUDIBASE] para [PROCESO]. Necesito roles, formulario, buscador, estados, alertas y panel. Define tablas, permisos, pantallas, integraciones y plan de construcción.

## E-book con Pandoc

> Ayúdame a convertir [ARCHIVO/CONTENIDO] en EPUB y PDF usando Pandoc. Propón estructura, metadatos, portada, tabla de contenidos, estilos, comandos reproducibles y validación. Conserva una fuente editable en Markdown.

## E-book con Sigil y Calibre

> Guíame para crear y validar un EPUB con Sigil y Calibre a partir de [ARCHIVO]. Incluye capítulos, portada, metadatos, índice navegable, revisión visual y comprobación en distintos lectores.

## Libro mantenible

> Crea la estructura de un libro con [QUARTO/MDBOOK] sobre [TEMA]. Incluye índice, capítulos, recursos, configuración de salida, comandos de publicación y un flujo para actualizarlo.

## Investigar

> Evalúa GPT Researcher para investigar [TEMA]. Revisa instalación, modelos, búsqueda web, citación, privacidad y costos. Propón una prueba pequeña antes de una investigación extensa.

## Revisar licencia

> Revisa la licencia vigente de [URL] y explícame si puedo usarlo para [PRODUCTO/SERVICIO]. Distingue uso interno, distribución, modificaciones y servicio alojado. Señala obligaciones y asuntos que requieren asesoría legal.

## Auditoría previa a publicación

> Revisa mi repositorio [OWNER/NOMBRE] antes de publicarlo. Busca secretos, permisos excesivos, dependencias vulnerables, datos personales, errores de configuración y ausencia de respaldo. No cambies nada hasta mostrarme los hallazgos.
